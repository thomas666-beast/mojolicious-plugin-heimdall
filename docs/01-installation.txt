HEIMDALL — INSTALLATION
=======================

1. Install the supplied release archive:

    cpanm ./Mojolicious-Plugin-Heimdall-0.002.tar.gz

   From the extracted distribution, you can also install with:

    cpanm .

   Requires Perl 5.26+, Mojolicious 9.48+, and CryptX 0.091+.
   See examples/README.md to run the complete login app.

2. Load the plugin in your Mojolicious app:

    use Mojolicious::Lite -signatures;

    plugin 'Heimdall';

    get '/' => sub ($c) {
      my $h = $c->heimdall;
      $c->render(text => 'Heimdall is loaded');
    };

    app->start;

3. Verify it works:

    perl myapp.pl get /

   Expected output: Heimdall is loaded

That is all. The plugin installs one helper: $c->heimdall.

It returns a facade object with five accessors:

    $c->heimdall->password
    $c->heimdall->random
    $c->heimdall->crypto
    $c->heimdall->jwt
    $c->heimdall->auth

Every other document uses one of these.
