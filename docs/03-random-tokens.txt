SECURE RANDOM VALUES
====================

WHAT IT DOES
  Generates cryptographically secure random strings. Suitable for
  session ids, password reset tokens, API keys, CSRF tokens.

  Do not use Perl's rand() or int(rand(...)) for any of these.

SNIPPET
  use Mojolicious::Lite -signatures;

  plugin 'Heimdall';

  get '/demo' => sub ($c) {
    my $r = $c->heimdall->random;

    my $token    = $r->token(32);          # 32 chars, A-Z a-z 0-9
    my $password = $r->password(20);       # 20 chars, mixed classes
    my $hex      = $r->string(16, '0123456789abcdef');

    $c->render(text => "token:    $token\n" .
                        "password: $password\n" .
                        "hex:      $hex\n");
  };

  app->start;

EXPECTED OUTPUT
  token:    qK3v8Nf2Rz9HmT4sWp7XcYb1Ld6JgAeU
  password: T7r!mQ2#vX9$kL4p
  hex:      a3f1c9e27b4d8065

METHODS
  $r->token($length)              alphanumeric, default 44
  $r->password($length)           mixed classes, default 16, minimum 4
  $r->string($length, $alphabet)  custom alphabet, default 32

IMPORTANT
  A password generated by ->password is random. It is NOT guaranteed
  to contain a digit or a symbol on every single call. If your policy
  requires at least one of each class, generate, then check, then
  regenerate if needed. Do not weaken the randomness to enforce
  composition rules.

COMMON USE: PASSWORD RESET
  my $token = $c->heimdall->random->token(48);
  $db->store_reset_token($user_id, $token, time + 3600);
  # send link: https://example.com/reset?token=$token

  When the user clicks:
    my $token = $c->param('token');
    my $row = $db->find_reset_token($token)
      or return $c->render(text => 'invalid', status => 400);
    return $c->render(text => 'expired', status => 400)
      if $row->{expires_at} < time;
