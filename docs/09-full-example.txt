COMPLETE LOGIN EXAMPLE
======================

The runnable source is examples/heimdall_demo.pl. The setup commands and
browser walkthrough are in examples/README.md. Keeping one source file
means the example is the same one exercised by the installation tests.

Read the source in this order:

1. Session settings: load a random secret from the environment and
   configure cookies.
2. Account loader: look up an already signed-in account by ID.
3. GET and POST /login: render a CSRF token, verify the submitted token
   and password, then store the verified user ID in the session.
4. GET /account and /admin: run the login guard; /admin independently
   checks the user's role.
5. POST /logout: validate the form token and clear the user's session data.

The demo binds to loopback when run using the documented command. It is
not a production account system. Before deploying a real app, replace
the in-memory users with a database, enforce account status and roles,
add login throttling, and use HTTPS. See 10-security-checklist.txt.
